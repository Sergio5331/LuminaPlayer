# Identidad de LuminaPlayer

- `lumina-logo.png`: logo utilizado en la interfaz y en los recursos de Qt.
- `lumina.ico`: icono del ejecutable de Windows.
- `app.rc`: recurso nativo que incorpora el icono al ejecutable.

Los iconos de los controles se dibujan mediante QPainter para conservar nitidez con distintas escalas de pantalla.
